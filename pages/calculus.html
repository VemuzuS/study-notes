∫ 微積分

整理極限、連續與微分的核心觀念，作為考前快速索引。

← 回到課程首頁

1. 重要概念

  • 極限描述 x 接近某值時函數的趨勢。
  • 連續需要極限存在、函數值存在，而且兩者相等。
  • 導數代表瞬時變化率或切線斜率。
  • 可微可以推出連續。

2. 重要公式或規則

f'(x) = lim(h→0) [f(x+h)-f(x)] / h
(xⁿ)' = n xⁿ⁻¹
(fg)' = f'g + fg'
(f/g)' = (f'g - fg') / g²

3. 常見題型

  • 使用極限定義求導數。
  • 判斷函數在哪些點連續。
  • 使用乘法、除法與鏈鎖律微分。

4. 容易搞錯的地方

  • 極限存在不代表函數值一定存在。
  • 連續不一定可微。
  • 使用鏈鎖律時不要漏掉內層函數的導數。
